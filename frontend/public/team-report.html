AIRPORT TIMETWIN · TEAM HANDOFF · 13 SEPTEMBER 2026

คู่มือทดลอง Airport TimeTwin

ระบบพยากรณ์คิว จำลองทางเลือก และแปลงผลเป็นคำแนะนำการเดินทางสำหรับผู้โดยสาร

เปิดเว็บไซต์เริ่ม Guided DemoOperationsPassenger

ลิงก์นี้เป็น public preview ชั่วคราว ต้องเปิด Mac และ Docker ของเจ้าของโปรเจกต์ไว้ ผู้ทดลองทุกคนแชร์สถานการณ์เดียวกัน กรุณาผลัดกันกด Reset หรือ Submit

ทดลองใน 3 นาที

  1. เข้า Guided Demo แล้วกด Start / restart guided demo
  2. ดู demand เพิ่มขึ้นและคิวอนาคต ระบบจะเปลี่ยนหน้าด้านขวาตามขั้นตอน
  3. เปรียบเทียบ No Action / Open A5 / Redirect / Combined
  4. เดโมบันทึกการยอมรับคำแนะนำและแสดงผลจำลอง
  5. เข้าสถานการณ์ผู้โดยสาร: Safe Time 34 → 11 เมื่อเปลี่ยน C8 → E7
  6. ดู Performance; ใช้ Pause/Resume/Next step หากต้องการเล่าเอง

หน้าที่ควรลอง

  • Future Flow: Current/+15/+30/+60 และ Presentation tools สำหรับ slider/route motion
  • Simulator: เลือกกลยุทธ์ ตรวจตารางเปรียบเทียบ และ Submit recommendation; เปิด Before/After ใน Presentation tools
  • Situations: Investigate → Analyse options
  • Flights: ค้นหา TT401 และดู ground timeline
  • Journey Flow: เปลี่ยน horizon ดูปริมาณเข้าแต่ละ checkpoint
  • Performance: ผลกระทบแยกจากความแม่นยำโมเดล
  • Sources: แหล่งข้อมูลและความสดของ cache
  • Decision log: เหตุผลและประวัติการตัดสินใจ

ข้อเท็จจริงที่ใช้ในการนำเสนอ

ข้อมูลสนามบิน อากาศ และตำแหน่งอากาศยานเป็น public caches จาก OurAirports, Open-Meteo และ OpenSky ส่วนเที่ยวบิน ผู้โดยสาร 580 ราย คิว เลน สัมภาระและงานภาคพื้นเป็น SYNTHETIC ผลพยากรณ์และเวลาที่ประหยัดเป็น SIMULATED

Simulated MVP Result — Not actual airport performance.

ภาพสนามบินเป็น AI-generated illustration ไม่มีการสั่งงานสนามบินจริง Confidence ยังเป็น heuristic เป้าความแม่นยำบาง horizon ยังไม่ผ่าน และไม่มี ML model ถูก promote
